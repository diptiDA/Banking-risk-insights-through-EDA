# Banking Risk Insights through Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a banking customer dataset to identify patterns, trends, and factors influencing customer risk. The analysis provides valuable insights into customer demographics, financial behavior, and risk characteristics, supporting data-driven decision-making in the banking sector.

---

## 🎯 Objectives

- Understand the distribution of customer demographics and financial attributes.
- Identify factors influencing customer risk levels.
- Analyze relationships between numerical and categorical variables.
- Detect missing values, duplicates, and outliers.
- Generate business insights through statistical analysis and visualizations.

---

## 📂 Dataset

The dataset contains **3,000 banking customer records** with features such as:

- Client ID
- Age
- Gender
- Nationality
- Occupation
- Income Band
- Risk Weighting
- Loyalty Classification
- Fee Structure
- Properties Owned
- Credit Score
- Account Balance
- Other customer-related attributes

## 📋 Project Workflow

### 1. Data Collection
- Imported the banking customer dataset into Jupyter Notebook.

### 2. Data Understanding
- Explored dataset shape, columns, data types, and summary statistics.

### 3. Data Cleaning
- Checked missing values.
- Removed duplicate records.
- Corrected inconsistent values.
- Verified data quality.

### 4. Exploratory Data Analysis (EDA)
- Performed descriptive statistical analysis.
- Analyzed categorical and numerical variables.
- Studied customer distributions.

### 5. Data Visualization
- Histograms
- Box Plots
- Count Plots
- Scatter Plots
- Regression Plots
- Correlation Heatmap
- Pair Plot

### 6. Insight Generation
- Identified customer risk patterns.
- Compared income groups and occupations.

- Detected outliers affecting business analysis.

### 7. Conclusion
- Summarized findings to support better customer risk assessment and business decision-making.

## 💡 Key Insights

- Income level showed a significant relationship with customer risk.
- Certain occupations exhibited higher average risk weighting.
- Outliers were identified in financial attributes such as account balance.
- Correlation analysis highlighted relationships among numerical variables.
- Customer segmentation revealed distinct financial behavior patterns.
